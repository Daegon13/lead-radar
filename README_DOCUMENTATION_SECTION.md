## Lead Radar

Lead Radar es una herramienta local-first de prospección comercial para encontrar negocios con capacidad de pago, necesidad comercial y brecha digital detectable. No busca generar listas enormes de contactos: busca oportunidades de calidad para que Diego pueda llamar con un diagnóstico claro y una propuesta concreta.

Frase guía:

> Lead Radar no busca negocios sin web; busca negocios con dinero, necesidad comercial y brecha digital detectable.

## Estado actual

La app actual permite gestionar leads, editar información, calcular prioridad, importar/exportar JSON/CSV y usar una sección de prospección simulada. La próxima evolución es separar la prospección mock en providers, crear un motor CLI local con CSV/JSON y luego integrar fuentes abiertas como Overture Places, Foursquare OS Places u OpenStreetMap/Overpass.
