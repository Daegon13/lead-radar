# Ideal Customer Profile — Lead Radar

## Definición general

El cliente ideal de Lead Radar es un negocio local de servicios o alto ticket, con capacidad de pago, necesidad de confianza, búsqueda local activa, contacto público disponible y presencia digital incompleta.

Definición compacta:

> Negocio local de servicio o alto ticket, ubicado en zona comercial o urbana, con contacto público, señales de actividad real, necesidad de confianza/reputación y una brecha digital detectable.

## Criterios positivos

Un negocio es buen candidato si cumple al menos 5 de estas señales:

1. Tiene ticket medio o alto.
2. Depende de conseguir consultas nuevas.
3. El cliente lo busca en Google antes de decidir.
4. Necesita transmitir confianza.
5. Tiene servicios, fotos, casos, ubicación o trabajos para mostrar.
6. Usa WhatsApp, teléfono o redes para captar consultas.
7. No tiene web propia o tiene una web débil.
8. El dueño, encargado o decisor parece accesible.
9. Tiene presencia en mapas, redes o directorios.
10. Opera en una zona con poder adquisitivo medio/alto.

## Criterios negativos

Bajar prioridad o descartar si:

- No hay teléfono, WhatsApp, email ni red social clara.
- El negocio parece cerrado o inactivo.
- Es una cadena/franquicia grande.
- Ya tiene una web fuerte y actualizada.
- El rubro es de margen bajo.
- El local parece de subsistencia o sin capacidad de inversión.
- No hay señales de demanda ni reputación.
- La fuente del dato es débil o antigua.
- El contacto parece personal y no comercial.
- La propuesta de web no tendría impacto claro en ventas o confianza.

Regla dura:

> Sin contacto público, nunca prioridad A.

## Rubros Tier 1 — Prioridad máxima

Estos rubros deben tener mayor peso en el score porque una sola conversión puede justificar el costo de una web.

| Rubro | Por qué es buen cliente | Oferta ideal |
|---|---|---|
| Centros de estética premium | Visual, ticket medio/alto, redes activas, necesidad de confianza | Landing/web con tratamientos, fotos, WhatsApp y SEO local |
| Clínicas odontológicas | Alto valor por paciente, confianza, agenda, búsqueda local | Web profesional con servicios, equipo, ubicación y CTA |
| Clínicas privadas pequeñas | Autoridad, reputación, claridad de servicios | Web institucional + agenda/contacto |
| Inmobiliarias | Ticket muy alto, captación de propietarios/compradores | Web catálogo + formularios + WhatsApp |
| Constructoras | Alto valor por proyecto, portafolio visual | Web portfolio + servicios + casos |
| Arquitectos/interioristas | Necesitan mostrar trabajos y confianza estética | Portfolio visual + contacto cualificado |
| Abogados | Cliente de valor alto, confianza, especialidad | Web sobria + servicios + autoridad |
| Contadores | Servicios recurrentes y confianza | Web profesional + consultas + formularios |
| Gestorías | Necesitan claridad, procesos y contacto | Web de servicios + WhatsApp + FAQs |

### Señales fuertes en Tier 1

- Nombre de marca trabajado.
- Zona comercial o premium.
- Fotos profesionales o semi-profesionales.
- Buenas reseñas o movimiento visible.
- Instagram activo pero sin web.
- Dominio inexistente, roto o abandonado.
- Servicios de alto valor explicables en una web.

## Rubros Tier 2 — Muy buenos, filtrar por calidad

| Rubro | Por qué sirve | Cuidado |
|---|---|---|
| Veterinarias clínicas | Búsqueda local, confianza, urgencia | Priorizar clínicas sobre pet shops genéricos |
| Academias privadas | Captan alumnos, necesitan reputación | Puede haber estacionalidad |
| Psicólogos | Confianza y búsqueda por especialidad | Profesionales individuales pueden pagar menos |
| Nutricionistas | Marca personal y agenda | Filtrar por presencia profesional |
| Fisioterapeutas | Servicios recurrentes, confianza | Priorizar centros sobre individuos aislados |
| Talleres especializados | Urgencia, confianza, búsqueda local | No todos valoran diseño premium |
| Barberías premium | Visual, reservas, marca, WhatsApp | Evitar barberías genéricas de bajo ticket |
| Peluquerías premium | Visual, recurrencia, redes | Filtrar por zona/estética |
| Estudios de tatuaje premium | Portfolio, confianza, reservas | Muy Instagram-dependientes |
| Gimnasios boutique/pilates/yoga | Marca, comunidad, agenda | Filtrar por propuesta diferencial |

## Rubros Tier 3 — Solo con señales fuertes

Estos rubros pueden servir, pero no deberían ser el foco inicial salvo que el sistema detecte señales comerciales claras.

- Cafés con marca.
- Restaurantes con identidad visual.
- Tiendas de ropa con marca propia.
- Florerías/decoración.
- Servicios espirituales/tarot/terapias con marca clara.
- Tiendas de productos artesanales o diseño.

Señales mínimas para subir prioridad:

- Buena estética.
- Fotos cuidadas.
- Zona fuerte.
- WhatsApp o reservas.
- Instagram activo.
- Sin web propia.
- Producto/servicio diferenciable.

## Rubros a excluir inicialmente

Excluir o dejar en prioridad D salvo caso excepcional:

- Kioscos.
- Almacenes comunes.
- Autoservicios chicos.
- Carnicerías comunes.
- Ferreterías pequeñas.
- Puestos de comida sin marca.
- Comercios sin contacto público.
- Negocios con pinta de subsistencia.
- Cadenas grandes.
- Franquicias con web corporativa.

No se excluyen por falta de valor humano, sino porque suelen tener menor probabilidad de pagar una web profesional freelance.

## ICP inicial recomendado

Para el MVP real de prospección, comenzar con estos 6 rubros:

1. Centros de estética premium.
2. Clínicas odontológicas.
3. Inmobiliarias.
4. Constructoras/arquitectos/interioristas.
5. Abogados/contadores/gestorías.
6. Veterinarias clínicas.

Segunda ola:

7. Academias privadas.
8. Barberías/peluquerías premium.
9. Estudios de tatuaje premium.
10. Gimnasios boutique/pilates/yoga.

## Ejemplos de clientes ideales

### Lead A — Centro de estética premium

- Zona: Punta Carretas.
- Instagram activo.
- WhatsApp visible.
- Sin web propia.
- Servicios: depilación láser, estética facial, aparatología.
- Señal: rubro visual y ticket medio/alto.
- Pitch: convertir Instagram + búsquedas locales en consultas por WhatsApp.

### Lead A — Clínica dental

- Zona: Pocitos.
- Buenas reseñas.
- Teléfono visible.
- Web inexistente o vieja.
- Servicios de alto valor.
- Pitch: confianza, servicios, equipo profesional, agenda y SEO local.

### Lead B — Barbería premium

- Zona: Cordón.
- Instagram activo.
- Usa agenda externa.
- No tiene dominio propio.
- Pitch: consolidar presencia propia sin reemplazar Instagram/Fresha.

### Lead C — Café chico

- Zona: barrio no premium.
- Instagram poco activo.
- Sin reseñas visibles.
- Contacto incompleto.
- Acción: revisar manualmente, no llamar primero.

### Lead D — Kiosco

- Bajo ticket.
- Sin marca diferencial.
- Sin contacto digital.
- Descartar.

## Cómo traducir el ICP al producto

El ICP debe impactar en:

- Filtros de búsqueda.
- Categorías soportadas.
- Pesos del scoring.
- Priorización A/B/C/D.
- Generación de argumento de venta.
- Vistas de cola de llamadas.
- Reportes de conversión por rubro.
